https://docs.microsoft.com/en-us/dotnet/framework/wcf/feature-details/how-to-configure-a-port-with-an-ssl-certificate

Add a listener:
netsh http add iplisten ipaddress=0.0.0.0:11235

netsh http delete sslcert ipport=0.0.0.0:11235
netsh http add sslcert ipport=0.0.0.0:11235 certhash=<CertificateThumbprintWithNoSpaces> appid={790C242A-DAA6-46FF-8E04-B1EB280F3BA2}

NOTE: Also watch out for the special character that the certificate manager inserts at the front of the thumbprint.

To be able to run as non-admin:
netsh http add urlacl url=https://yoururl:port/ user=DOMAIN\user

Your username is probably YourMachineName\YourUsername

Finally: add the port via the advanced firewall tool, specifying the port as a Local port, and specifying All programs (as the server doesn't actually open the port...)


.\SetupTLSCertificate.ps1 -PfxCertificate "Path\To\Pfx.pfx" -Hostname my.hostname.com -Port 11235 -ServerUsernameWithDomain domain\username
